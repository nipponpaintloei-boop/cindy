# CINDY — สร้าง APK จากมือถือเครื่องเดียว (ไม่ต้องมีคอม)

โปรเจกต์นี้ตั้งค่าให้ GitHub Actions เป็นคนติดตั้ง Capacitor + build APK ให้ทั้งหมด
คุณแค่ต้องอัปโหลดไฟล์ขึ้น GitHub ผ่านเบราว์เซอร์ในมือถือ ที่เหลือ GitHub ทำให้เอง

## ขั้นตอน

1. **สร้าง repo ใหม่** ที่ github.com (เปิดผ่านเบราว์เซอร์มือถือก็ได้) → New repository → ตั้งชื่อ เช่น `cindy-app` → Create (ไม่ต้องติ๊ก README)

2. **อัปโหลดไฟล์ทีละไฟล์** ด้วยปุ่ม "Add file → Create new file"
   ในช่องชื่อไฟล์ ให้พิมพ์ path เต็มตามนี้ (พิมพ์ `/` จะสร้างโฟลเดอร์ให้อัตโนมัติ) แล้ววางเนื้อหาไฟล์ที่ตรงกันจากที่แตกซิปไว้ ลงในกล่องข้อความ จากนั้นกด Commit:
   - `package.json`
   - `capacitor.config.json`
   - `.github/workflows/build-apk.yml`
   - `www/index.html`
   - `www/app.js`
   - `www/sw.js`
   - `www/manifest.webmanifest`
   - `www/icon.svg`

   เปิดไฟล์จากในตัวจัดการไฟล์ของมือถือด้วยแอปแก้ไขข้อความ (เช่น เปิดด้วย Text Editor / Code Editor) → เลือกทั้งหมด → คัดลอก → วางใน GitHub

3. พอ commit ไฟล์สุดท้าย (`.github/workflows/build-apk.yml`) เสร็จ **GitHub Actions จะเริ่ม build อัตโนมัติทันที**

4. ไปที่แท็บ **Actions** ของ repo → จะเห็น workflow "Build CINDY APK" กำลังรัน (ใช้เวลาประมาณ 5–8 นาที)

5. เมื่อรันเสร็จ (เครื่องหมายถูกสีเขียว) → กดเข้าไปในรันนั้น → เลื่อนลงไปที่ **Artifacts** → ดาวน์โหลด `cindy-debug-apk` (เป็นไฟล์ .zip)

6. แตะไฟล์ zip ที่ดาวน์โหลดมาเพื่อแตกไฟล์ (มือถือ Android ส่วนใหญ่แตะแล้วแตกซิปให้เองในแอป Files) จะได้ `app-debug.apk`

7. แตะ `app-debug.apk` เพื่อติดตั้ง — ถ้าเจอ "บล็อกการติดตั้งจากแหล่งที่ไม่รู้จัก" ให้เข้าไปอนุญาตในตั้งค่าเครื่องแล้วลองใหม่

## หมายเหตุ

- นี่คือ **debug APK** ใช้ทดสอบเองได้เลย ไม่ต้องเซ็นชื่อ (signing) แต่ถ้าจะอัปขึ้น Play Store ต้องทำ release build + signing key ต่างหาก (ค่อยทำทีหลังได้)
- ทุกครั้งที่แก้โค้ดใน `www/` แล้ว commit ใหม่ → GitHub Actions จะ build APK ตัวใหม่ให้อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม
- แจ้งเตือนแบบเรียลไทม์ (ทำงานแม้ปิดแอป) จะเริ่มทำงานเฉพาะใน APK นี้เท่านั้น ถ้าเปิดผ่านเบราว์เซอร์ปกติจะยังเป็นแบบเดิม (เตือนตอนเปิดแอป)
